# Enterprise Warehouse Management System (WMS)

A robust, cloud-based Warehouse Management System utilizing Java and Spring Boot. This platform automates core warehouse operations, including real-time inventory tracking, receiving, and order picking workflows.

## Tech Stack
* **Backend:** Java 17+, Spring Boot 3.x
* **Database:** PostgreSQL
* **Data Access:** Spring Data JPA / Hibernate

## Running Locally
Make sure you have PostgreSQL running locally with a database named `wms_db`.
Run the following command to start the backend:
`.\mvnw spring-boot:run`
